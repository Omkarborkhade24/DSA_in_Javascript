Dijkstra's Algorithm (Finding the Fastest Route)
If a standard Graph tells us who is connected, a Weighted Graph tells us the cost of that connection. Think of Google Maps: it's not just about knowing that City A connects to City B; you need to know it takes 50 miles to get there.

Dijkstra's algorithm finds the absolute shortest path between a starting node and an ending node.

To make this work, we need a helper structure called a Priority Queue. Unlike a regular Queue (First-In, First-Out), a Priority Queue serves whoever has the highest priority first—like a hospital emergency room. In Dijkstra's, the "highest priority" is the node with the shortest distance.
