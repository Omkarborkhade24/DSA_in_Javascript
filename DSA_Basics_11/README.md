Tree Traversal: Breadth-First Search (BFS)
In our last step, we used Depth-First Search (DFS) to go all the way down a single branch before checking the rest of the tree.

Breadth-First Search (BFS) takes a different approach: it reads the tree level by level, from top to bottom, left to right.

To do this, BFS uses a Queue (our FIFO structure from Concept #2!). We put the root in the queue, then loop: take a node out, print it, and put its children at the back of the queue.
